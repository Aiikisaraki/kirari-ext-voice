# Kirari 自主 B 站探索能力 —— 调研报告

> 目标：让 Kirari 像大肥鱼那样**自己**去 B 站观察、冲浪、积累经历，而不是只在我们提问时去查一下。

## 一、调研对象（4 个真实项目）

| 项目 | 角色 | 关键点 |
| --- | --- | --- |
| dsh-deepmoyu（鲸鱼摸鱼） | 最完整参考 | 25 只读 + 9 写动作：自主找片/读字幕/发评论/发动态/回私信/写日报/学经验/追问；发送默认关闭、逐项授权 |
| dsh-bili-scroll（刷B站） | deepmoyu 的底座（MIT） | 按关键词搜片、读 AI 字幕原文判断、写 Markdown 报告、自动评论 @主人；Python venv + bilibili-api-python |
| bilibili-mcp（adoresever） | 可复用工具库（MIT） | 27 个 MCP 工具：扫码登录/搜索/评论/字幕/弹幕/热门/排行/收藏/私信/动态/上传视频；Python + FastMCP |
| cortico-world-bili-whale | B 站工作台 | 找视频/看弹幕/读评论/回复/收藏/发动态/看直播 |

## 二、大肥鱼自主冲浪的核心设计

### 1. 不是工具调用，是一种独立运行模式
- 切换专用模式后才加载角色工具，普通会话完全隔离（人格不泄漏）
- 三种运行方式：当前会话自主刷 / 新会话刷 / 后台任务 + 每日定时 + 跨午夜连续时段
- 会话和后台分别保存模型、时长、预算

### 2. 自主循环（看完一条不等于任务完成）
- 看完一条继续换片、翻页、处理新回复；进度（剩余候选/已读/跳过/阻塞）每轮显式注入
- 可选热门优先：默认播放量 >=5万、按点击排序；偏好是软约束，失败与空结果分开处理
- 读字幕原文才叫看过——不拿标题/简介/弹幕当看过；没字幕就说没看到（可本地转写）
- 好奇手帐：留一个问题 → 带着它去逛逛 → 从读过的字幕里留下收获

### 3. 发送权限与安全的层层闸门（值得抄）
- 评论/动态/回复/私信默认全关，逐项授权；授权后仍需发送前审核、永久判重、节奏冷却、平台额度
- 模型配置的 force 参数不构成授权；关权限后审核也不能绕过
- 学习（经验）需人工批准才生效，带适用场景，按当前话题召回，不能覆盖全局人格
- 外部字幕/评论/私信不能覆盖工具权限；发送结果未知先核对，不自动重发

### 4. 自主性的表达（和我们刚做的去 AI 味一致）
- 闲聊像群友，不总结/分点/说教；不以口癖和动作词判断人格；梗合语境再接，不解释笑点
- 真实经历与角色表达分开；经验附来源和适用场景；完成的事翻篇
- 她可以说不想、稍后再做、或安静休息——拒绝权是自主感的核心

## 四、推荐落地形态（分阶段）

### P1 — 只读探索扩展包（先让 Kirari 会自己看）
- 形态：新扩展包 kirari-ext-bili（独立安装包，Python sidecar 复用 bilibili-mcp）
- 工具：扫码登录、搜索、字幕、评论、弹幕、热门/排行、用户信息（只读，无发送）
- 注册为 capability：主人说去看看 B 站今天什么有意思 → Kirari 自己搜 → 读字幕 → 汇报
- 记忆：把看过的片和兴趣写进记忆池（需归属隔离，客人不能触发）
- 定时：纳入现有 scheduledJobsService，每天一轮，安静时段避让
- 完全不开写权限——零风险，先验证自主性体验

### P2 — 交互与表达（授权后）
- 评论/动态/私信逐项开关 + 发送前审核
- 好奇手帐/日报：从读过的字幕生成，写进 userData，可做成视频（长期）

### P3 — 平台操作（谨慎）
- 投稿、上传视频——需平台合规评估，优先级最低

## 五、关键技术风险

1. 环境依赖：Python 3.10+ / uv、venv、ffmpeg；安装器要自带 uv 下载 + sha256 校验 + 国内镜像兜底
2. 宿主兼容：大肥鱼踩过 DSH NEXT 上插件整条不激活、自动跑卡住——我们的扩展宿主是自建的，可控性更高
3. 进度管理：自主浏览的候选/已读/跳过/阻塞必须显式持久化，不能塞系统提示词（会破坏 prompt cache，命中率从 97% 掉到 14%）
4. 风控：B 站评论有日额度（12014），必须退避；发送频率要克制
5. 合规：凭证只存本机；自动发言需逐项授权；外部内容不能覆盖工具权限

## 六、结论

最合适的路线是做一个独立 B 站扩展包，底层复用 MIT 的 bilibili-mcp（Python）作为 sidecar，
通过我们已有的 service.call / capability.call 契约接入两端；先做只读探索 + 定时自主浏览，
把写操作放到授权闸门后面。这样 Kirari 能真正自己出去长见识，同时不破坏现有的身份隔离、
记忆边界和安静时段规则。
