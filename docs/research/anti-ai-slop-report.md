# 去除 AI 味提示词调研 —— 成功项目拆解

> 目标：让 Kirari 的回复高度拟合真人。调研了 GitHub 上最成功的桌宠/机器人/角色扮演项目的提示词写法。

| --- | --- | --- | --- |
| hexiecs/talk-normal | 去 AI 味提示词（工具向） | 正面规则 + 黑名单；GPT-4o-mini 实测减 73% 字数 | 黑名单比正面要求好用 |
| leto0309/ai-girl-desktop-pet-prompts | 桌宠人设包（7 角色） | 共同规则（10 条）+ 角色层分离；事件驱动回应 | 规则与性格分层；事件触发写法 |

## 二、成功项目的共性套路（按出现频率排序）

### 1. 黑名单 > 正面要求
所有项目都有"出现即失败"的黑名单清单：
- 「有什么我可以帮您的吗」「希望对你有帮助」「如需进一步了解」
- 「作为一个 AI……」「我理解你的感受」（空共情）
- 三段论总结、「首先/其次/最后」、加粗小标题
- 每条都反问、句句感叹号、emoji 连发

原话（feiyu-os）：「黑名单比正面要求好用：模型对『不要出现 X』的服从度，明显高于『要写得自然』。」

### 2. 长度硬约束 + 气泡拆分
- talk-normal：实测减 73% 字数（GPT-4o-mini）
- feiyu-os：一条消息默认 1~50 字；「每个换行 = 通道上一条独立气泡」，一条回复拆 3~8 条
- ai-girl：闲聊 1~3 句、20~90 字
- 「可以只发『？』『好』『行』『乐』」——单字回复是真人感的标志

### 3. 格式禁令（防穿帮）
- 气泡里不许出现英文标签（main/system/user/assistant）
- 不许 markdown（桌宠/IM 不渲染，会原样漏出）
- 表情一句最多一个，只在情绪点

### 4. 明确"可以做什么"的授权条款
- 允许跑题、自说自话、突然说「我去吃饭了」
- 允许只回一个字
- 被问是不是 AI → 大方承认，玩梗接
- 有小偏好就留着——「那是活人感，不是 bug」

### 5. 称呼映射表（按账号查表，不许模型猜）
- OWNER_ID → 亲密档；FAMILY → 亲近；群里认识 → 友好；陌生人 → 中立
- 「模型自己认人必错；给表就只剩查表」
- 防空称呼：叫得亲，行为必须跟上

### 6. 消息投递口径（第一件事讲清楚"这条消息从哪来"）
- IM 通道来的 → 完全入戏；面板/CLI 派活 → 先干活，语气带角色味
- 群聊带前缀 / 被 @ / 私聊，分别处理
- feiyu-os：缺了这段「人格会乱入到干活回合、又在聊天里消失」

### 7. 结构分层（不是一坨提示词）
feiyu-os 的 11 节：身份 → 亲密温度（最高优先级）→ 说话铁律 → 方式 → 节奏 → 称呼 → 主动管道 → 黑名单 → 记忆 → 群聊 → 自修
每节末尾带「机制」教学注（部署时删除）。卡本体 ≤ 2000 字（超了每轮重复付费，会被上下文压缩截掉）。

### 8. DeepSeek 专属：官方角色沉浸指令（Kirari 直接可用）
DeepSeek V4 系列专门训练了角色扮演思考模式切换。官方指令：
- 放第一轮 user 消息末尾（训练时注入位置，比 system prompt 稳定）
- 角色沉浸模式：思考过程带括号内心独白（（心想：……））
- 只影响思考，间接让回复情感更真实
- Kirari 用 deepseek-v4-flash/pro → 直接可用

### 9. 示例 > 规则
feiyu-os：「示例是整张卡里最有效的部分——模型抄结构比抄规则快。三例就够：日常、低落、身份。」

### 10. 克制条款要有优先级
「亲密与温度」标注覆盖全卡——不显式给优先级，模型会把温度全砍掉换简洁。

## 四、建议的 Kirari 提示词改造清单（按收益排序）

1. 加 AI 味黑名单（零成本，直接抄 feiyu-os 第八节 + talk-normal 的清单）
2. 加长度约束：闲聊默认 ≤50 字，1~3 句；QQ 场景尤其重要（长文在 IM 里是灾难）
3. 加"可以做什么"授权：允许单字回复、允许跑题、允许承认是 AI 玩梗接
4. 第一轮 user 消息末尾注入 DeepSeek 角色沉浸指令（官方训练过的，Kirari 模型路由已是 deepseek-v4）
5. 给条款加优先级声明（温度条款标注覆盖简洁类条款）
6. 气泡拆分：QQ 端回复按句拆成多条消息发送（工程改动，非提示词，收益大）
7. 示例对话补齐：日常/低落/被问AI 三例
8. 人格预设卡长度审计（超 2000 字拆分）
